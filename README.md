# Blender-Model
3D Architectural Temple – Blender Animation Project This project is a 3D architectural modeling and animation created using Blender. The scene features a detailed and symmetrical temple/palace-inspired structure with multiple towers, domes, pillars, stairways, corridors, and decorative architectural elements. 

The project focuses on 3D modeling, architectural design, texturing, materials, lighting, camera composition, and animation. The model was built with attention to symmetry, proportions, and detailed structural elements to create a visually rich architectural environment.
## Key Features
🏛️ Detailed 3D architectural structure
🧱 Custom modeling of buildings, towers, pillars, and decorative elements
🏗️ Symmetrical architectural layout
🛕 Multiple towers and dome structures
🪜 Detailed entrance and staircase design
🎨 Materials and colors applied to different architectural components
💡 Scene lighting and visual composition
🎥 Camera setup for animation and presentation
🔄 3D animation workflow using Blender
🖥️ Designed and rendered using Blender 3D
